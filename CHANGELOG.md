## [1.5.0] - 2026-09-12

### Added

- Added ESM support with `import agozilla from "agozilla"`.
- Added package exports for CommonJS and ESM consumers.
- Added browser and modern bundler compatibility.
- Expanded TypeScript definitions to cover the public API.
- Added support for TypeScript consumers using the complete Agozilla API.

## [1.4.0] - 2026-09-12

### Added

- Added `calendar()` API for human-friendly calendar date formatting.
- Added support for Today, Yesterday, Tomorrow, Last weekday, and Next weekday.
- Added calendar date formatting for older dates.
- Added tests for `calendar()`.
